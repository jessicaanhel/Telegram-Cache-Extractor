# Telegram Cache Extractor

Инструмент для расшифровки и просмотра **собственного** локального кэша Telegram Desktop (`tdata`) — извлекает фото, видео, стикеры и аудио из зашифрованного медиа-кэша и открывает их в удобном браузерном вьювере с сортировкой, поиском по проводнику и выгрузкой выбранных файлов в отдельную папку.

## Дисклеймер

Инструмент предназначен **только для восстановления собственных данных** из локального кэша своей же установки Telegram Desktop. Не предназначен для доступа к чужим аккаунтам или данным без явного разрешения владельца.

## Как работать
Пошарься по телеграм-каналу с закрытым доступом. Открывай фото, смотри видео. Данные о них сохраняются в кеше. Твоя задача - набить этот кеш своими залипаниями и просмотрами. Дальше открываешь программу, которую ты только что установил. Указываешь путь до твоей папки tdata в Telegram, указываешь куда выводить папку с медиа, когда программа их сформирует. Указываешь свой пин-код от приложения Telegram (если его нету, оставляешь пустым). Не волнуйся, эта инфа никуда не идет (можешь проверить код) просто телега иначе не даст вынуть файлы из кеша. Затем жмешь "Начать извлечение", ждешь когда закончится процесс. После завершения, Нажимаешь "Открыть галлерею": открывается html-страница с локальным мини-сервером. Можно смотреть медиа, а также выбирать нужные и формировать выбоку в отдельной папке (для этого и нужен сервер). Все

## Возможности

- Расшифровка `key_datas` и файлов кэша (`TDF$` / `TDEF`) на основе открытого формата хранения tdesktop
- Поддержка passcode (локального пароля Telegram Desktop), если он задан
- Определение типа файла по сигнатуре: JPEG, PNG, WebP, GIF, TGS (стикеры), MP4/WebM (видео), MP3/OGG/WAV (аудио)
- `Viewer.html` — локальная HTML-галерея со спойлерами по типам медиа, встроенным плеером для видео/аудио и лайв-поиском
- Клик по имени файла — открывает проводник Windows с выделенным файлом
- Выбор нескольких файлов чекбоксами → выгрузка в отдельную подпапку одним кликом

## Требования

- Python 3.9+
- `pip install pycryptodome pyperclip`
- Windows (функция "открыть в проводнике" рассчитана на `explorer.exe`; сама расшифровка кроссплатформенна)

## Как это работает

Приложение поднимает лёгкий локальный HTTP-сервер (`127.0.0.1`, случайный свободный порт) — он отдаёт `Viewer.html` и медиафайлы, а также обрабатывает клики "открыть в проводнике" и "собрать папку". Сервер живёт только внутри запущенного приложения и наружу (в сеть) не торчит.

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

В приложении:
1. Укажи путь до папки `tdata` (обычно `%AppData%\Telegram Desktop\tdata`, подставляется автоматически)
2. Укажи, куда сохранить извлечённые файлы
3. Если в Telegram Desktop задан Passcode Lock — введи его, иначе оставь поле пустым
4. Нажми **"Начать извлечение"**, дождись завершения, затем **"Открыть галерею"**

**!Галерею нужно открывать только через кнопку в приложении и не закрывать окно приложения, пока ей пользуешься — сервер живёт внутри процесса!**

## Сборка standalone `.exe`

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=icon.ico --add-data "icons;icons" --add-data "icon.ico;." --name "TelegramCacheExtractor" app.py
```

Готовый файл — в `dist/TelegramCacheExtractor.exe`.

## Сборка инсталлятора (Inno Setup)

В репозитории есть готовый `installer.iss`. Открой в Inno Setup Compiler, проверь путь до собранного `.exe` в секции `[Files]`, `Ctrl+F9` — инсталлятор появится в `installer_output/`.
